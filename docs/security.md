# 安全与公开信息规范

[返回文档目录](README.md)

## 公开配置与仓库文件

`PUBLIC_*` 是公开配置，只用于站点地址、仓库、反馈邮箱和备案信息。模型 Key、密码、Token、私钥和签名 keystore 不属于官网配置。

[.gitignore](../.gitignore) 排除环境文件、构建目录、测试产物、IDE缓存及常见私钥/签名文件。`.env.example` 保留字段说明，不包含秘密。提交前检查差异；首次公开或引入新资源时，也检查手机号、学号、私人账号、本机用户路径和个人截图。

## 用户与应用数据

官网不建立用户通知、群聊、任务或 AI 对话数据库，也不提供模型 Key 输入和上传功能。产品截图和反馈材料应移除个人来源、消息、账号及凭据。

App 的用户数据库和加密配置与安装包是不同内容；分发文件应核对版本、来源和哈希。官网许可证及静态托管配置不改变 Android 应用的权限或数据行为。

## 外部资源与反馈

链接、素材及依赖应有可核对的来源。新外部服务需要说明目的、数据范围和隐私影响；系统字体、静态资源和现有交互无需引入追踪 SDK。

公开 Issue 仅提供必要的设备信息和脱敏复现步骤。发现真实凭据泄露时先撤销相关凭据，再提供不含秘密的说明；涉及敏感细节时使用维护者提供的私密联系方式。

开发工具和第三方依赖许可证见[第三方声明](../THIRD_PARTY_NOTICES.md)。站点与应用的数据边界见[隐私说明](https://shunyoudeng.github.io/luoxu-web/privacy/)。

用户反馈统一邮箱：[luoxufeedback@163.com](mailto:luoxufeedback@163.com)。请先遮住隐私，不要附上 API Key 或密码；GitHub Issue 保留用于开发协作。
